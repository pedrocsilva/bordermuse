# Contributing

Read [AGENTS.md](AGENTS.md) for project constraints and [Development](docs/DEVELOPING.md)
for checks. Keep changes focused and describe the resulting behavior and validation.

New geometry ports must pass the shared corpus. New integrations should include
a small runnable example. Discuss changes to output geometry before implementing
them. See [Architecture](docs/ARCHITECTURE.md) and [the plan](docs/PLAN.md) for scope.
